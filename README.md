# class-photo-notion

아이폰에서 찍은 수업 사진을 Windows 11 노트북으로 바로 보내고, 노션에도 자동으로 정리할 수 있게 만든 프로젝트입니다.
수업시간 중 휴대폰으로 캡처한 사진을 메모 중인 노션에 올리는 과정이 번거로워서 만든 자동 업로드 서비스입니다.

## 설계와 역할

| 영역 | 구현 |
|---|---|
| Frontend | 단일 HTML 화면, 시간표·업로드 모드·사진 선택 |
| Backend | Express 요청 처리, 접속 코드 검사, Multer 파일 저장 |
| 외부 연동 | Notion 파일 업로드 및 페이지·DB 연결 |
| 로컬 기능 | Windows 클립보드 복사, 실패 시 경로 복사 시도 |

흐름: 아이폰 Safari → 노트북 Express 서버 → 로컬 저장 및 선택적 Notion 연동.
서버가 Notion 자격 증명을 보관하고 브라우저는 업로드 목적지와 파일을 전달합니다.

## 개선 기록
프로젝트 루트 전체를 정적 파일로 공개하던 설정을 제거하고 앱의 index.html만 제공합니다. 소스와 업로드 사진을 URL로 직접 조회하는 경로를 차단했습니다.

## 검증 범위
로컬 업로드와 외부 Notion 연동은 별개입니다. 실제 Notion 계정에서 페이지·데이터베이스 모드별 검증이 필요하며, Windows 클립보드 기능은 해당 운영체제에서 확인해야 합니다.


## 주요 기능

- 아이폰에서 사진 촬영 또는 선택
- 수업 시간표 등록 후 수업 시간에만 업로드 활성화
- 사진 선택 직후 자동 업로드
- 노션 기존 페이지에 이어 붙이기
- 노션 데이터베이스에 새 페이지 만들기
- 둘 다 동시에 업로드
- 노트북 로컬 저장
- 업로드 후 노트북 클립보드에 이미지 복사 시도
- 접속 코드 기반 업로드 보호

## 동작 방식

이 프로젝트는 노트북에서 서버를 실행하고, 아이폰이 그 서버에 접속하는 방식입니다.

그래서 아래 중 하나가 필요합니다.

- 아이폰과 노트북이 같은 와이파이에 연결
- 노트북이 아이폰 개인용 핫스팟에 연결
- 아이폰 USB 테더링으로 노트북 연결

또한 노션 업로드까지 하려면 노트북은 인터넷 연결이 가능해야 합니다.

## 1. 설치

Node.js LTS를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
```

## 2. 환경 변수 설정

프로젝트 루트에 `.env` 파일을 만듭니다.

예시:

```env
NOTION_API_KEY=여기에_노션_비밀키
APP_ACCESS_TOKEN=271987
PORT=3000
NOTION_VERSION=2026-03-11
MAX_UPLOAD_MB=20
```

### NOTION_API_KEY 발급 방법

1. `https://www.notion.so/my-integrations` 접속
2. `+ New integration` 클릭
3. Integration 생성
4. 생성 후 보이는 `Internal Integration Secret` 복사
5. `.env`의 `NOTION_API_KEY`에 붙여넣기

### APP_ACCESS_TOKEN 이란?

아이폰에서 앱에 접속할 때 입력하는 접속 코드입니다.

직접 정하면 됩니다.

예시:

- `APP_ACCESS_TOKEN=271987`
- `APP_ACCESS_TOKEN=my-class-photo`

비워두면 서버 실행 시 임시 6자리 코드가 콘솔에 표시됩니다.

## 3. 노션 연결

### 기존 페이지에 붙일 때

1. 사진을 붙일 노션 페이지 열기
2. 우측 상단 `...`
3. `Connections` 또는 `연결`
4. 만든 Integration 추가

### 데이터베이스에 새 페이지를 만들 때

1. 대상 노션 데이터베이스 열기
2. 우측 상단 `...`
3. `Connections` 또는 `연결`
4. 만든 Integration 추가

페이지/데이터베이스 주소는 웹앱에 URL 그대로 붙여 넣어도 됩니다.
서버가 ID를 자동으로 추출합니다.

## 4. 실행

```bash
npm start
```

정상 실행되면 콘솔에 이런 주소가 보입니다.

```text
http://192.168.x.x:3000
```

또는 아이폰 핫스팟/USB 연결이면 `172.20.x.x:3000` 형태가 보일 수 있습니다.

## 5. 아이폰에서 사용

1. 아이폰 Safari에서 콘솔에 나온 주소 열기
2. 접속 코드 입력 후 저장
3. 수업 시간표 등록
4. 노션 업로드 방식 선택
5. 페이지 URL 또는 데이터베이스 URL 입력
6. 사진을 찍거나 선택
7. 수업 시간 안이면 자동 업로드

## 6. 업로드 방식

- `기존 페이지에 이어 붙이기`
  기존 노션 페이지에 callout + 이미지 블록 추가
- `데이터베이스에 새 페이지 만들기`
  사진마다 새 페이지 생성 후 이미지 첨부
- `둘 다`
  위 두 동작을 동시에 수행
- `노트북 저장 + 클립보드만`
  노션 업로드 없이 로컬 저장만 수행

## 7. 체크 명령어

서버 문법 체크:

```bash
npm run check
```

## 8. 주의사항

- `.env`는 절대 GitHub에 올리면 안 됩니다.
- 이전에 노출된 노션 API 키가 있었다면 폐기 후 새로 발급받는 것이 안전합니다.
- 노션 업로드는 노트북의 인터넷 연결 상태에 영향을 받습니다.
- 클립보드 복사는 Windows 환경에서 시도되며, 일부 환경에서는 파일 경로 복사로 폴백될 수 있습니다.
